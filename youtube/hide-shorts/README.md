# YouTube: Hide Shorts

## What it does

Removes YouTube Shorts from the parts of the site where they are pushed at
you: the home feed, the Subscriptions feed, search results, the shelf under a
video on watch pages, the "Shorts" entry in the left sidebar, and the "Shorts"
tab on channel pages. Anything that links to `/shorts/` inside a video list
is hidden along with the shelf it sits in.

It does not block the `/shorts/` pages themselves — a Short opened by direct
link still plays. It hides, it does not redirect.

The script is a single stylesheet injected before the page renders, so Shorts
never flash into view and nothing needs to re-run when YouTube navigates
between pages.

## Where it runs

- `https://www.youtube.com/*`

## Install

Requires [Violentmonkey](https://violentmonkey.github.io/) for Firefox.

**[Install hide-shorts.user.js](https://raw.githubusercontent.com/inklikeurine/userscripts/main/youtube/hide-shorts/hide-shorts.user.js)**

Violentmonkey checks that link for updates automatically.

## Notes / caveats

- Permissions: none (`@grant none`).
- Network requests: none.
- Fragility: depends on YouTube's element names (`grid-shelf-view-model`,
  `ytm-shorts-lockup-view-model`, `ytd-reel-shelf-renderer`, …) and on Shorts
  links starting with `/shorts/`. When YouTube renames an element, that part
  of the page silently shows Shorts again; nothing breaks otherwise.
- The channel-page "Shorts" tab is matched by its English label, so it stays
  visible if the YouTube UI is set to another language. Everything else is
  language-independent.
- Uses the CSS `:has()` selector, which needs Firefox 121 or newer.

## Firefox only

Developed for Firefox and not tested in any other browser. Other browsers are
unsupported.
