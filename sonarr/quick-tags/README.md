# Sonarr: Quick Tags

## What it does

On a Sonarr series page, adds a green button with a tag and a plus sign to
the row of labels under the title, right after **Links** (where Sonarr's own
**Tags** label appears once a series has tags). Click it and a small box
opens just below with the series' current tags, so you can tag a show without
opening the Edit dialog.

The box works like Sonarr's own tag field:

- Start typing and existing tags that contain those letters are suggested.
  Use the arrow keys or the mouse to pick one.
- **Enter**, **Tab**, **space** or **comma** adds what you typed. A name that
  doesn't exist yet becomes a new tag. Like in Sonarr, tag names can only
  use a–z, 0–9 and `-`.
- Click a tag (or its **×**) to remove it. **Backspace** in an empty box
  removes the last one.
- Every add and remove is **saved straight away**. Sonarr's own Tags label on
  the page updates by itself.
- Click anywhere outside the box to close it (anything still typed is added,
  as in Sonarr). **Esc** closes it and throws away what's typed.

It only changes tags. Nothing else about the series is touched, and no files
are moved.

Requires **Sonarr 5.0.0.2800 or newer** (v5). Sonarr v4 is not supported.
Works in light and dark themes (it uses Sonarr's own colours).

## Where it runs

- `*://*:8989/*` — any address on port 8989, Sonarr's default
  (for example `http://192.168.1.10:8989`).

On any page that isn't Sonarr it does nothing.

### Using Sonarr at a different address

If you reach Sonarr through a domain name or a different port (for example
`https://sonarr.example.com`), add that address in Violentmonkey. It is kept
when the script updates, and it never ends up in this public repository.

1. Click the Violentmonkey icon in the toolbar, then **Open Dashboard**.
2. Under **Installed scripts**, find **Sonarr: Quick Tags** and click
   **Edit** (the `</>` button).
3. Open the **Settings** tab.
4. Under **Custom metadata**, in **@match rules**, add one line per address,
   ending in `/*`:

   ```text
   https://sonarr.example.com/*
   ```

   Leave **Keep original** ticked so it still runs on port 8989 too.
5. Click **Save & Close**, then reload your Sonarr tab.

If Sonarr lives under a path (for example `https://example.com/sonarr`), add
`https://example.com/sonarr/*`. The script reads Sonarr's URL base from the
page, so it works there too.

## Notes / caveats

- Permissions: none (`@grant none`). The script runs in the Sonarr page itself.
- Network requests: only to your own Sonarr, through the same API its v5
  web page uses (`/api/v5`), using the API key the Sonarr page already holds. It fetches
  your series list and tag list, creates new tags, and saves tag changes
  through Sonarr's Mass Editor endpoint. Nothing goes anywhere else.
- Fragility: it finds the **Links** label and its row by the readable part
  of Sonarr's style class names (`SeriesDetails-module_links_…`,
  `SeriesDetails-module_chipsRow_…`). If a Sonarr update renames those, the button
  silently doesn't appear. Nothing breaks, and the script needs an update.
- If Sonarr refuses a change (for example the connection dropped), the tag
  goes back to how it was and the reason is shown under the box.
