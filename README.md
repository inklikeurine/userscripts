# userscripts

A collection of browser userscripts generated by AI.

**Use at your own risk.** Every script in this repository was written by an AI
agent. They are provided as-is, with no warranty, no guarantee of correctness,
and no promise of maintenance. Read a script before you install it.

**Firefox only.** These scripts are developed and tested exclusively in
Firefox. Chrome and other browsers are untested and unsupported.

## Install

You need [Violentmonkey](https://violentmonkey.github.io/) for Firefox — it is
the only userscript manager these scripts are written for; Tampermonkey and
Greasemonkey are unsupported. Then open the raw `.user.js` link in a script's
README and Violentmonkey will offer to install it. Updates are picked up
automatically from the same link.

## Userscripts

Scripts are grouped by the website they target. Each script lives in its own

## License

AI code generators are trained on enormous pools of public code, released under
every license imaginable — permissive, copyleft, and non-commercial alike. The
origin of any individual generated line is untraceable. Output built from that
pool cannot honestly be owned by anyone.

My position: code built from the commons belongs to the commons. Since no one can know which
licenses any given line was originally released under, AI-generated code should
be treated as unlicensable — public domain by default.
