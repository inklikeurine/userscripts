# Magnet Grabber

## What it does

Clicking a `magnet:` link copies it to the clipboard instead of handing it to a
torrent client, and a small "Magnet copied!" popup appears next to the pointer
for a moment. If the copy fails, the popup says "Copy failed".

Only left-clicks on `<a href="magnet:…">` links are affected; every other link
behaves normally.

## Where it runs

- `*://*/*`

## Install

Requires [Violentmonkey](https://violentmonkey.github.io/) for Firefox.

**[Install magnet-grabber.user.js](https://raw.githubusercontent.com/inklikeurine/userscripts/main/any-site/magnet-grabber/magnet-grabber.user.js)**

Violentmonkey checks that link for updates automatically.

## Notes / caveats

- Permissions: none (`@grant none`).
- Network requests: none.
- Runs on every site (hence the `any-site` folder). It is a single click
  listener, so cost is negligible.
- Fragility: depends only on plain `<a href="magnet:…">` links; magnet
  buttons that open a client via JavaScript are not intercepted.

## Firefox only

Developed for Firefox and not tested in any other browser. Other browsers are
unsupported.
